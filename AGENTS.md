## Project Summary

A template for Python projects: `uv`, `ruff`, `import-linter`, `jscpd`, `pre-commit` + `lefthook`, Docker and a Makefile. `src/main.py` is a placeholder entrypoint.

## Standards & Guidelines

@.github/CONTRIBUTING.md

- Comments only when necessary, this includes docstrings; don't add one just to restate what the name/code already say.
- Be concise, short README, no emojis.
- No extra feature, focus on what has been asked.
- Every new command goes through the `Makefile`; don't document ad-hoc `uv run ...` invocations.
